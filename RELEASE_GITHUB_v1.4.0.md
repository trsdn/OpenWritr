# OpenWritr v1.4.0

This release adds a standard in-app About and Help surface so users can identify OpenWritr, find its source, get support, and report problems.

## Added

- About OpenWritr entry in the menu bar
- Installed version and build information
- Clear open-source and maintainer attribution
- Direct links to:
  - Project website
  - GitHub source repository
  - New issue reporting
  - Downloads and releases
  - MIT license

## Install or Upgrade

Requires macOS 14 or later and Apple Silicon (M1 or later).

Quit OpenWritr, download the ZIP or DMG from this release, and replace `OpenWritr.app` in `/Applications`. Grant Microphone and Accessibility permissions if prompted.
